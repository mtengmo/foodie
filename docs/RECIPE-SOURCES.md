# Recipe catalogue sources

Reviewed 2026-10-24. The catalogue is a curated static pilot of twelve bilingual recipes, not a bulk scraper or runtime API integration. Nine recipes are original Foodie text released under CC0; three are adapted Wikibooks recipes under CC BY-SA 4.0. No external images are copied. Nutrition data remains attributed separately to Livsmedelsverket under CC BY 4.0.

Credit: **Wikibooks contributors**, with authorship history available through each source page. English adaptations and Swedish translations retain [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Each recipe carries its pinned URL, attribution and change notice. The preview and saved copy display these; JSON exports/imports retain them. Licence metadata is optional for older schema-1 templates, whose original Foodie texts remain CC0. Newly labelled CC BY-SA copies require valid source metadata. HTTPS source URLs are validated before import.

The gram amounts and portions assigned here are editorial choices, not automatic conversions of unspecified units. Both language versions use the same ingredient mapping. Recipe text has been reviewed against the cited pages and the data snapshot; this is not a claim that recipes were kitchen-tested.

## Requested original additions

- **Korvstroganoff med ris:** 19%-fat falukorv, 15%-fat cream, tomato purée, onion and Swedish mustard; dry rice and its intended absorbed water are included. Adjust the water to the rice packet and actual yield when saving a copy.
- **Entrecôte med rostad sötpotatis:** raw boneless entrecôte, peeled raw sweet potato, broccoli, oil and salt. Quantities refer to raw edible input weights.
- **Rostad sötpotatis:** a separate four-serving side dish.

All use source food IDs, complete frozen details on copying and the existing recipe calculator. Values are estimates, with missing nutrients flagged; cooking losses and actual finished weight are not inferred. Use measured final weight for cooked per-100-g concentration.

## Adding more recipes

1. Read an eligible source and its licence, pin the revision and retain required credits.
2. Review ingredient preparation states and gram weights; record proxies, omissions and assigned servings explicitly.
3. Author both language versions, retaining the source's applicable licence for adaptations.
4. Check every mapping against the current snapshot, known macro values, source links and JSON round trips.
5. Review mobile preview/copy/export and attribution before publication. Do not auto-import large catalogues or depend on an unofficial ICA endpoint without a separately reviewed integration.
